# Objective
Create the Cargo workspace for the browser: a virtual root manifest and three member crates,
`engine` and `net` (libraries) and `browser` (a binary). This is the skeleton every later
cycle builds in; it holds no browser code yet.

# Outcome
The workspace builds and tests from a clean state, and the browser binary runs.
- **Evidenced by:**
  1. `cargo build --workspace` exits 0.
  2. `cargo test --workspace` exits 0 and reports exactly one passing test for `engine` and
     exactly one for `net` (2 in total; there were 0 before this task, since no workspace
     existed).
  3. `cargo run -p browser` exits 0 and prints exactly `agentic-browser` on one line.
  4. `cargo tree -p engine` prints `engine` and nothing beneath it; `cargo tree -p browser`
     shows `engine` and `net` beneath `browser`.

# Task context
- The repository already holds `deny.toml` at its root, which allows only permissive
  licences. This repository is `MIT OR Apache-2.0`.
- `engine` will take data in and return structures out, and may never perform I/O: no
  `std::fs`, `std::net`, `std::process`, `std::env`. `net` will do fetching later. `browser`
  is the application that uses both.

# Deliverables
- **CREATE** `Cargo.toml`: a virtual manifest (`[workspace]` only, no `[package]`),
  `resolver = "3"`, members `crates/engine`, `crates/net`, `crates/browser`, and a
  `[workspace.package]` table with `edition = "2024"`, `license = "MIT OR Apache-2.0"`,
  `publish = false`, `version = "0.1.0"`.
- **CREATE** `crates/engine/Cargo.toml`, `crates/net/Cargo.toml`, `crates/browser/Cargo.toml`:
  each inherits `edition`, `license`, `publish` and `version` from the workspace.
  `browser` has path dependencies on `engine` and `net`; the other two have no dependencies.
- **CREATE** `crates/engine/src/lib.rs` and `crates/net/src/lib.rs`: each a public
  placeholder function `name() -> &'static str` returning its crate's name, and one
  `#[cfg(test)]` unit test asserting that value.
- **CREATE** `crates/browser/src/main.rs`: prints `agentic-browser` and exits.
- **CREATE** `Cargo.lock`: generated by the build, committed as is.

# Instructions
1. CREATE the root `Cargo.toml` as described.
2. CREATE the three crates under `crates/`, with the manifests and sources described.
3. Run the four evidence commands, in order.

# Constraints
- No dependency from crates.io, and no dev-dependencies. The only dependencies are
  `browser` → `engine` and `browser` → `net`, as path dependencies.
- No code beyond the placeholders: no DOM, parser, window or networking code.
- Do not edit `deny.toml`, `docs/` or `.claude/`.
- If a command fails twice, stop and report it verbatim.

# Response format
One line per Deliverable, marked done or not done. Then one line per evidence item above,
with the command's summary line (the test result lines verbatim for item 2, the printed line
for item 3, the tree output for item 4). No other prose.
